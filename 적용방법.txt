파파고 검수 번역 등록 방법

1. 네이버 파파고(https://papago.naver.com/)에서 일본어 코디명을 한국어로 번역하고 결과를 직접 확인합니다.
2. papago_verified.json 파일에 아래 형식으로 등록합니다.
   "일본어 원문": {"ko": "파파고에서 확인한 한국어", "verified": true}
3. GitHub 저장소의 최상위 폴더에 app.js와 papago_verified.json 두 파일을 업로드합니다.
4. Render 배포가 끝나면 새로고침합니다.

중요:
- 검수되지 않은 예시 항목은 verified:false 이므로 파파고 검수 결과로 표시되지 않습니다.
- 기존 임시 번역은 계속 표시되고, verified:true인 이름만 검수된 번역으로 덮어씁니다.
- 일본어 원문은 사이트의 카드에 표시된 원문을 정확히 복사해야 합니다.
- 번역 등록은 GitHub 파일을 수정하는 방식이며 사이트 안에서 직접 편집하는 기능은 없습니다.
- API 키, 네이버 클라우드 가입은 필요 없습니다.
- 공식 파파고 번역 결과를 자동 수집하지 않으며, 실제 검수는 사용자가 해야 합니다.
