업데이트: 공식 코디 팝업 전신 이미지 우선 수집 (검증 필요)

1. GitHub 저장소 최상위에 app.py, app.js, style.css, requirements.txt 업로드
2. Commit changes 후 Render 배포 완료 대기
3. /api/status에서 수집 오류 확인
4. 코디 화면에서 전신 이미지 확인

이번 수정은 목록의 썸네일을 전신으로 확대하지 않고,
각 코디 HTML 요소에 연결된 별도 팝업/상세 이미지 URL을 탐색합니다.
별도 이미지가 발견되지 않으면 잘못된 배너나 상반신 썸네일을
대신 표시하지 않습니다. 따라서 빈 이미지가 생길 수 있습니다.

주의: 현재 실행 환경에서는 aipri.jp 직접 접속이 불가해
실제 팝업 HTML 구조를 검증하지 못했습니다. 전신 이미지 자동 수집의
완료를 보장하지 않습니다. 공식 사이트의 팝업이 JavaScript로 이미지를
생성한다면 해당 JavaScript 데이터 구조를 추가로 분석해야 합니다.
