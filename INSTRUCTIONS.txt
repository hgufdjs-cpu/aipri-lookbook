아이프리 코디 도감 복구 + 배너 카드 제거 패치

1. ZIP 압축 해제
2. GitHub 저장소 https://github.com/hgufdjs-cpu/aipri-lookbook
3. Add file > Upload files 에서 app.py, app.js, style.css, requirements.txt 업로드
4. Commit changes
5. Render 자동 재배포 완료 후 브라우저 새로고침

수정:
- 이미지가 전부 사라진 시험용 코드 대신 이전 썸네일 수집 방식 복구
- 이미지가 가로로 긴 배너인 경우 서버가 HTTP 410으로 구분
- 410을 받은 카드 전체를 화면에서 제거
- 파일명에 명백한 배너 표기가 있는 데이터는 목록에서 제외
- 일반적인 이미지 오류는 코디 카드까지 삭제하지 않음

제한:
- '가로형'이 아닌 글자 배너는 자동 판별이 안 될 수 있음
- 원본 사이트 전신 팝업 이미지 주소는 아직 확인되지 않아 이번 파일은 전신 이미지 패치가 아님
- Render의 기존 DB가 유지되면 잘못 저장된 이미지 주소는 남아 있을 수 있음
- 이미지 사용 조건을 확인해야 함
